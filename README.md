# 備品BOX

Delta Chatのwebxdc用アプリ「備品BOX」の配布ファイルと操作マニュアルです。鍵・工具・PCなどの備品について、誰が借りているか、返却予定日、返却状況を記録するためのアプリです。

アプリ本体は **[Supply_BOX_1.0.0.xdc](Supply_BOX_1.0.0.xdc)** です。操作マニュアルでは、一般の利用者向けに登録・貸出・返却の手順を図表で説明しています。

| ファイル | 用途 |

## マニュアルの内容

1. 基本の流れと利用開始前の確認
2. 画面の見方と各タブの役割
3. 備品の登録
4. 貸出の登録
5. 返却と期限の確認
6. 履歴の検索、CSV出力、集計の見方
7. 備品情報の編集・削除と困ったときの対応

## アプリの導入と起動

1. 端末に `Supply_BOX_1.0.0.xdc` を保存します。拡張子を変更したり、解凍したりする必要はありません。
2. Delta Chatで、備品を管理する相手またはグループのチャットを開きます。
3. 添付ファイルとして `Supply_BOX_1.0.0.xdc` を選び、送信します。
4. 送信されたアプリのメッセージを開きます。参加者も、同じチャットの同じアプリメッセージから起動してください。
5. 「備品BOX」の画面が表示されたら、マニュアルに沿って操作します。最初は見本データを確認し、記録の共有と保持を試してください。

端末によって添付・起動ボタンの名称や配置は異なります。運用中は、参加者が同じアプリメッセージを使うようにしてください。別のチャットや新しく送ったアプリメッセージに、既存の記録が引き継がれるとは限りません。

マニュアルのHTML版は説明文書です。アプリの `index.html` を通常のブラウザーで開くだけでは、チャットのメンバーと記録を共有できません。

## 基本の操作

基本の操作は「備品を登録する → 利用可の備品を選ぶ → 貸出を確定する → 実物の返却を確認して返却を記録する」です。

## 利用開始前に確認すること

- 調査対象のコードには、備品11点・履歴10件の見本データが含まれています。実際の記録と混同しないでください。
- データの永続保存とwebxdcの更新受信処理には、実機での確認が必要です。管理担当者が複数端末で登録・貸出・返却を試し、アプリを閉じて開き直しても記録を確認できることを確かめてください。
- 画面の「同期中」は、全員の端末への到達を保証する表示ではありません。
- 「返却」は確認画面なしで実行されます。実物と対象の記録を照合してから押してください。
- 備品を削除すると、関連する貸出履歴も削除されます。復元機能はありません。
- CSV出力は現在の検索・絞り込み条件に一致する履歴が対象です。完全なバックアップではなく、再取込み機能もありません。
